# Prettier Code Studio — `prettier.abishek.in`

A professional, fullscreen, browser-based multi-language code formatter:
- **Prettier 3 Engine:** Real-time formatting for JavaScript, TypeScript, HTML, CSS, SCSS, JSON, Markdown, YAML, GraphQL, SQL, and Python.
- **Customizable Rules:** Tab width (2, 4, 8), Tabs vs Spaces, semicolons, single vs double quotes, trailing commas, print width, and bracket spacing.
- **Minifier Mode:** 1-click minification for JS, CSS, HTML, and JSON.
- **Interactive Diff Viewer:** Line-by-line diff comparing raw input against formatted output.
- **Productivity Features:** Auto-detects programming language on drag-and-drop, sample loaders for all languages, 1-click copy, and file download.
